# Rishitha Galicherla — Portfolio

A single-page portfolio showcasing my work in **React apps**, **Figma design**, and **Power BI dashboards**.

**Live site:** [rishitha333.github.io/freelancer_portfolio](https://rishitha333.github.io/freelancer_portfolio)

## What's on the site

- **Power BI dashboards.** Interactive sales analytics built with DAX, drillthrough, custom report-page tooltips, and field parameters, including the [Maven Roasters dashboard](https://github.com/Rishitha333/maven-roasters-dashboard) (149K transactions).
- **React and full-stack projects.** Applications built with React, Next.js, TypeScript, Flask, and MongoDB.
- **UI/UX design.** Interface work and design systems built in Figma.

## About this repo

The site is a static page served with GitHub Pages: `index.html` holds the page and `images/` holds the project visuals. To run it locally, clone the repo and open `index.html` in a browser. No build step is needed.

```bash
git clone https://github.com/Rishitha333/freelancer_portfolio.git
cd freelancer_portfolio
# open index.html in your browser
```
