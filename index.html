Machine learning · Full-stack Code available

MUSE — Multilingual Sentiment & Sarcasm Engine

A system that listens to speech and works out not just whether the speaker is positive or negative, but whether they mean it. Sarcasm is the hard case: the words and the tone disagree, so reading the transcript alone gets it wrong.

It reads both signals against each other — language through mBERT embeddings and a trained classifier, tone through pitch and energy features from Librosa — then fuses them. Around that sits a full pipeline: Whisper transcribes the audio and detects the language, a router translates across seven languages using NLLB-200 or Marian, and RoBERTa handles sentiment.

It runs as a deployed application with JWT authentication, bcrypt-hashed passwords, per-user analysis history in MongoDB, an admin panel, and PDF export with embedded Noto fonts so Indic scripts render properly rather than as boxes.

  • Wired the translation router so each language pair goes to the right model.
  • Built and deployed the React and Flask application end to end, including auth, history, and the admin panel.

Desktop application · Live data Code available

EnviroTrack — Environmental Monitoring & Alerts

A Java desktop application that reads sensor data as it arrives and shows temperature, humidity, and air quality in a form someone can scan in a second, with alerts when a reading crosses a threshold.

The real problem was legibility under change — values updating constantly need a layout that holds still, and a schema that stays queryable as historical readings pile up.

The multi-sensor chart is drawn from scratch in Graphics2D rather than pulled from a library, and a Python layer runs alongside the Java client for linear-regression forecasting and z-score anomaly detection.
